AssetPicker

A free, cross-platform asset & file picker you embed in your web app. Open it in a modal, let users browse a storage — GitHub, Google Drive, EnterMediaDB or your own adapter — and get the picked asset back.

How it works

  1. Add a button to your app and open the picker (this demo does it above).
  2. The user browses a storage — the sidebar tree is folder navigation; single-click a folder to open it.
  3. Click a file to select it, then press Select — the chosen asset is returned to your app.

Features

  • Easy integration — mount it anywhere and get a callback with the picked asset.
  • Multiple storages — GitHub, Google Drive, EnterMediaDB, or a custom adapter.
  • Search across all configured storages at once.
  • Authentication & proxy support for private and CORS-restricted sources.
  • Configurable — pick limit and allowed types / extensions.

About this demo

It uses the built-in dummy adapter (random folders and files, no login). Click Try it, open a storage, single-click folders to browse, click a file to select it, then Select. The picked asset appears at the top.
